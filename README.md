# متجر المنتجات والبطاقات الرقمية | Digital Products E-Commerce

منصة تجارة إلكترونية متكاملة للمنتجات والبطاقات الرقمية والاشتراكات، مبنية بأحدث التقنيات:
- **React + TypeScript (Vite)**
- **Tailwind CSS v4 (Full RTL Arabic)**
- **Framer Motion** (تأثيرات وانتقالات ثلاثية الأبعاد)
- **Supabase** (Auth & Database مع دعم العمل دون اتصال والنسخ الاحتياطي)
- **WhatsApp Direct & Bulk Checkout** (الشراء السريع عبر واتساب مع رسائل ديناميكية ذكية)
- **Multi-Currency System** (دعم الدولار الأمريكي USD، الليرة التركية TRY، والليرة السورية SYP بمزامنة لحظية أو تسعير يدوي)

---

## 🚀 المميزات الرئيسية

1. **واجهة عربية بالكامل (RTL)**:
   - تصميم متجاوب فائق السرعة بمظهر تطبيق هاتف أصيل (Native App Feel).
   - شريط تنقل سفلي للهواتف الذكية (Bottom Navigation Bar) وشريط علوي لسطح المكتب.
   - تبديل سلس بين الوضع الليلي (Dark Mode) والوضع الفاتح (Light Mode).
   - شريط أخبار متحرك (News Ticker) وسلايدر عروض ترويجية (Hero Slider).

2. **نظام أسعار الصرف والعملات المتعددة**:
   - دعم التبديل المباشر بين 3 عملات: **USD ($)** و **TRY (₺)** و **SYP (ل.س)**.
   - شريط لحظي يعرض أسعار الصرف الحالية المعتمدة.
   - نمطان للإدارة:
     - **وضع المزامنة الحية (API Mode)**: جلب أحدث أسعار الصرف العالمية آلياً.
     - **وضع التسعير اليدوي (Manual Mode)**: تحديد أسعار الصرف حسب السوق المحلي.

3. **أنماط المنتجات والشراء عبر واتساب**:
   - **منتجات بالباقات (Packages Mode)**: مثل شدات ببجي (60 UC، 325 UC، 660 UC)، بطاقات بلايستيشن، اشتراكات كانفا وتيليجرام بريميوم.
   - **منتجات قياسية (Standard Mode)**: منتجات بسعر ثابت وميزات محددة مثل مفاتيح ويندوز 11 واشتراك ChatGPT Plus.
   - **حالات المنتجات**: نشط (Active)، نفد من المخزون (Out of Stock)، أو مخفي (Hidden).
   - **طلب فوري عبر واتساب**: رسالة منسقة تلقائياً بصيغة:
     `[بادئة الإدارة] + [اسم المنتج] + [الباقة] + [الكمية] + [السعر الإجمالي بالعملة المختارة] + [رقم الطلب والملاحظات]`.
   - **سلة مشتريات ذكية**: إمكانية جمع أكثر من منتج وباقة وإرسال الطلب مجمعاً للواتساب بنقرة واحدة.

4. **لوحة إدارة وتحكم متكاملة (Admin Dashboard)**:
   - إدارة كاملة (CRUD) للمنتجات، الباقات، التصنيفات المتفرعة (Nested Categories).
   - إدارة شريط الأخبار، سلايدر العروض، والأسئلة الشائعة (FAQs).
   - مدير أسعار العملات مع محاكي تسعير مباشر.
   - إدارة رقم الواتساب، البادئة، وروابط وسائل التواصل.
   - فحص مباشر للاتصال بـ Supabase وزر تعبئة البيانات النموذجية بضغطة واحدة.

---

## 🗄️ إعداد قاعدة بيانات Supabase (SQL Schema)

قم بنسخ محتوى الملف `schema.sql` ولصقه في **SQL Editor** داخل لوحة تحكم مشروعك في [Supabase](https://supabase.com) واضغط **Run**.
